核心特性

为大表与协作而生

六个核心能力，覆盖从渲染、公式到部署的完整链路，全部开源。

Canvas 大表引擎

CANVAS GRID ENGINE

  • 10 万行级虚拟滚动，只绘制可视区域
  • 稀疏列式 gzip 传输 + 键集分页，深翻页不塌
  • 分组、冻结列、撤销重做、拖拽填充

公式引擎 · 119 函数

FORMULA ENGINE

  • 119 函数 + 14 运算符，兼容飞书多维表格公式目录
  • 官方示例 golden test 逐条断言，带文档溯源
  • 依赖图级联重算，公式列即改即得

实时协作 · SSE

REALTIME COLLABORATION

  • SSE 单元格级推送，变更即时可见
  • 在场状态：谁正在编辑哪一格
  • 断线自动握手回放 + 协作撤销 / 重做

视图与字段

VIEWS & FIELDS

  • 文本 / 单选 / 多选 / 日期 / 复选框 / 公式 / 关联字段
  • 筛选、排序、分组，多视图全员共享
  • 记录详情抽屉：字段总览、动态与行历史

权限与账户

AUTH & ACCOUNTS

  • HMAC 无状态 token，口令全部由环境变量注入
  • 角色菜单权限 + 账户管理面板
  • 代码与配置文件不内置任何默认口令

轻量自托管

LIGHTWEIGHT SELF-HOSTING

  • 单个 Spring Boot JAR + 一个 MySQL 8
  • Docker Compose 一键启动，健康检查内置
  • 首次启动自动建表并生成示例数据

诚实说明

PolyTable 目前视图类型较少（以表格视图为主，看板 / 日历 / 表单视图在 路线图 中），社区也还处于早期阶段，插件与生态不及成熟项目丰富。如果你需要开箱即用的全场景体验， 飞书多维表格或 NocoDB 可能更合适；如果你在意数据主权、大表性能与部署简单，欢迎试试 PolyTable。

注：竞品信息基于各项目 / 产品 2026-11 前后的官方公开资料整理，许可与能力可能随版本变化，请以各官方文档为准； 「约 5 万行上限」为飞书多维表格公开文档口径。

快速开始

5 分钟跑起来

推荐

应用 + MySQL 一次拉起，首次启动自动建表。

源码运行

适合开发与二次开发，改完代码直接起服务。

JDK 17+ Maven 3.8+ MySQL 8

打开 http://localhost:8080/ops/

演示账户

首次启动自动创建演示用户 陈明：初始口令 = 姓名拼音首字母 + OPS_AUTH_PASSWORD_SUFFIX（未设置后缀时即为 CM），仅限本地体验； 同时生成含公式列的示例表。

管理员面板

配置 OPS_ADMIN_USERNAME / OPS_ADMIN_PASSWORD 后， 通过 /ops/admin.html 管理账户与角色。

生产部署前

务必设置 OPS_AUTH_PASSWORD_SUFFIX 与 OPS_AUTH_TOKEN_SECRET （不设置则重启后所有登录态失效），完整配置见仓库内 application.yml 注释。
