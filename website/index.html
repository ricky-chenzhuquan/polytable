核心特性

一张表该有的能力，都在一个 JAR 里

从渲染、公式到协作与权限，PolyTable 把多维表格的核心能力做进单个 Spring Boot 应用，依赖只有一个 MySQL。

Canvas 大表引擎

自研 Canvas 渲染管线，10 万行级数据滚动依旧流畅；稀疏列式 + gzip 传输压缩带宽，键集分页让翻页深度不再拖慢查询。

  • 10 万行级滚动流畅
  • 稀疏列式 gzip 传输
  • 键集分页（Keyset Pagination）

公式引擎

内置 119 个与飞书多维表格目录兼容的公式函数，命名与行为对齐其公开文档，从成熟产品迁移的表格可以低成本过渡。

  • 119 个飞书兼容函数
  • 依赖图驱动级联重算
  • golden test 全量回归覆盖

实时协作

基于 SSE 的单元格级推送：谁改了哪格、谁正在编辑哪格一目了然。完整操作日志可追溯，轻量实现不依赖额外中间件。

  • SSE 单元格推送
  • 在场状态（谁在编辑哪格）
  • 操作日志

视图与字段

文本、数值、日期、单选 / 多选、成员、公式等常用字段类型开箱即用；筛选、排序、分组与多视图组合，把一张表按需切成不同切面。

  • 常用字段类型齐全
  • 筛选 / 排序 / 分组
  • 多视图并存

安全与权限

接口走 HMAC token 校验，菜单与操作按角色收敛；数据库口令、签名密钥等敏感配置全部通过环境变量注入，不落盘、不进仓库。

  • HMAC token 校验
  • 角色菜单权限
  • 字段级权限

轻量自托管

一个 Spring Boot JAR 加一个 MySQL 就是全部依赖，Docker Compose 一键拉起；数据完全留在你自己的服务器上。

  • 单 JAR + 单 MySQL
  • Docker Compose 一键启动
  • 数据完全自持

快速开始

两分钟跑起来

推荐 Docker Compose 一键启动；也可以拉源码用 Maven 直接运行。所有口令均通过环境变量注入，不要写进文件或仓库。

1

Docker Compose 一键启动

需要 Docker + Compose v2
# docker-compose.yml —— 新建空目录，保存为该文件 services: mysql: image: mysql:8.4 environment: MYSQL_ROOT_PASSWORD: ${POLYTABLE_DB_PASSWORD:?请在 .env 中设置} MYSQL_DATABASE: polytable volumes: - mysql-data:/var/lib/mysql healthcheck: test: ["CMD", "mysqladmin", "ping", "-h", "localhost"] interval: 5s retries: 30 polytable: # TODO: 替换为正式镜像地址 image: ghcr.io/YOUR_GITHUB_NAME/polytable:latest depends_on: mysql: condition: service_healthy ports: - "8080:8080" environment: POLYTABLE_DB_URL: "jdbc:mysql://mysql:3306/polytable?useUnicode=true&characterEncoding=utf8" POLYTABLE_DB_USERNAME: root POLYTABLE_DB_PASSWORD: ${POLYTABLE_DB_PASSWORD} POLYTABLE_AUTH_SECRET: ${POLYTABLE_AUTH_SECRET:?请在 .env 中设置} volumes: mysql-data:
然后执行
$ docker compose up -d
2

源码运行

需要 JDK 17+ 与 Maven
# 克隆并启动（首次运行会自动下载依赖） $ git clone https://github.com/YOUR_GITHUB_NAME/polytable.git # TODO: 替换为正式仓库地址 $ cd polytable $ mvn spring-boot:run
默认入口 http://localhost:8080/ops/ 数据库口令、HMAC 密钥等敏感配置通过环境变量注入。
