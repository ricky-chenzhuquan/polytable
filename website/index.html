Core features

Built for big grids and realtime collaboration

Six core capabilities covering the full pipeline — rendering, formulas, and deployment — all open source.

Canvas big-grid engine

CANVAS GRID ENGINE

  • Virtual scrolling at 100k-row scale — only the visible viewport is drawn
  • Sparse columnar gzip transfer + keyset pagination — deep paging stays fast
  • Grouping, frozen columns, undo/redo, and drag-fill

Formula engine · 119 functions

FORMULA ENGINE

  • 119 functions + 14 operators, compatible with the Feishu Bitable formula catalog
  • Official examples locked in by golden tests, each with doc-level traceability
  • Dependency-graph cascading recalc — formula columns update instantly

Realtime collaboration · SSE

REALTIME COLLABORATION

  • Cell-level SSE push — changes land instantly
  • Presence awareness: see who is editing which cell
  • Automatic rejoin & replay after disconnects, plus collaborative undo/redo

Views & fields

VIEWS & FIELDS

  • Text / single-select / multi-select / date / checkbox / formula / link fields
  • Filter, sort, and group — multiple views shared with the whole team
  • Record detail drawer: field overview, activity, and row history

Permissions & accounts

AUTH & ACCOUNTS

  • Stateless HMAC tokens — every secret injected via environment variables
  • Role-based menu permissions + an account management panel
  • No default credentials baked into code or config files

Lightweight self-hosting

LIGHTWEIGHT SELF-HOSTING

  • A single Spring Boot JAR + one MySQL 8
  • One-command Docker Compose startup with built-in health checks
  • First boot auto-creates the schema and seeds sample data

An honest note

PolyTable currently offers fewer view types (table view first; kanban / calendar / form views are on the roadmap), and the community is still early — plugins and ecosystem aren't as rich as mature projects. If you want an out-of-the-box, everything-included experience, Feishu Bitable or NocoDB may suit you better; if you care about data sovereignty, big-grid performance, and simple deployment, give PolyTable a try.

Note: competitor info is compiled from official public materials as of around Nov 2026; licenses and capabilities may change between versions — defer to each vendor's documentation. The "~50k-row cap" reflects Feishu Bitable's public documentation.

Quick start

Up and running in 5 minutes

One command brings up the service — the default entry point and demo accounts work out of the box.

Docker Compose

Recommended

Brings up app + MySQL in one shot; the schema is created automatically on first boot.

Open http://localhost:8080/ops/

Run from source

For development and contribution — edit the code and start the server directly.

JDK 17+ Maven 3.8+ MySQL 8

Open http://localhost:8080/ops/

Demo account

First boot creates demo user Chen Ming: initial password = pinyin initials of the name + OPS_AUTH_PASSWORD_SUFFIX (CM when no suffix is set) — for local exploration only; a sample table with formula columns is generated as well.

Admin panel

Set OPS_ADMIN_USERNAME / OPS_ADMIN_PASSWORD, then manage accounts and roles at /ops/admin.html.

Before going to production

Always set OPS_AUTH_PASSWORD_SUFFIX and OPS_AUTH_TOKEN_SECRET (without them, every login session is invalidated on restart). Full configuration is documented in the comments inside the repo's application.yml.
